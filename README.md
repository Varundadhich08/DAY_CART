🛒 DayCart — Smart Grocery Subscription & Instant Delivery Platform

DayCart is a modern grocery delivery platform designed to simplify daily shopping. It allows users to subscribe to essential products like vegetables, fruits, bread, milk and eggs while also supporting instant delivery for urgent needs—combining the best of subscription-based and quick commerce models.

🚀 Features
🔁 Smart Subscription System
Subscribe to daily essentials (milk, eggs, etc.)
Select delivery days (Mon–Sun)
Pause / Resume subscriptions anytime
Skip deliveries easily
Auto-payment via wallet

⚡ Instant Delivery (Quick Commerce)
Order groceries instantly (10–20 min delivery concept)
Real-time order status tracking
Separate section for fast-moving products

💰 Wallet System
Add money to wallet
Automatic deductions for subscriptions
Transaction history tracking
Ready for Razorpay integration

👤 User Authentication
Secure login/signup (Supabase Auth)
Email-based authentication
Session management

📦 Order Management
Place and manage orders
Track delivery status
View order history

🧠 Smart Suggestions (Planned / AI Ready)
Product recommendations based on usage
Subscription suggestions for frequent items
